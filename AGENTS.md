# Diretrizes para Agentes de IA (HuaPlay)

- **Gemini**: Responsável por escrever e ajustar código da aplicação e configurações.
- **Codex**: Responsável por validação, builds, operações Git e deploy.
- **Autorização de Deploy**: Publicar/deployar exclusivamente após autorização do usuário (deploy atual da versão 1.0.4 já autorizado).
- **Higiene Git & Commits**:
  - Commitar mudanças coerentes e devidamente verificadas.
  - Nunca incluir segredos (arquivos de credencial/service-account, keystores), bancos de dados (`*.db`), APKs ou artefatos gerados.
- **Preservação**: Preservar o layout e a versão desktop.
- **Repositório**: `https://github.com/AngeLZinS2/HuaPlay.git`
- **Comunicação**: Comunicação sempre enxuta e objetiva.
